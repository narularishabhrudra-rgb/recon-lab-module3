## Steps
1. **Setup:** start the sandbox app (DVWA or Juice Shop) locally.
2. **Identify:** browse the app, note inputs, forms, login, and cookies in DevTools.
3. **Test (Burp/ZAP):**
   - Route the browser through the proxy
   - Run a ZAP automated scan on the local app
   - Manually test one input for injection and one for XSS
   - Test access control by changing an ID in a request
4. **Show the result:** screenshot the evidence.
5. **Fix:** show the vulnerable code and the secure version.
6. **Re-test:** confirm the issue is resolved.
7. **Document:** summarize in the vulnerability report.
