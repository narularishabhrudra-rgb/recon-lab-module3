# Module 3: Web Application Security

Internship project (Day 11 to Day 15). This repository contains my OWASP analysis, vulnerability report, remediation recommendations, and demo walkthrough from a Secure Web Application Lab (**Identify → Test → Fix → Document**).

> **Ethics note:** All testing was done only in my own sandbox (DVWA / OWASP Juice Shop running locally). Never test applications without explicit permission.

## Method: Identify → Test → Fix → Document
1. **Identify**: map the app, list inputs, login flows, and sessions
2. **Test**: check for OWASP Top 10 issues using Burp Suite / OWASP ZAP
3. **Fix**: apply secure coding changes and re-test
4. **Document**: record evidence, risk, and remediation
